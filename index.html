4. CFG Grammar Rules

The following simplified grammar rules are used by this demonstration website.

Rule Grammar
Rule 1 Contract → Clause
Rule 2 Clause → Party Obligation Object
Rule 3 Obligation → shall | must | may | will
Rule 4 Condition → If Condition, Clause
Rule 5 NestedClause → ( Clause )

These are simplified demonstration rules, not a complete grammar for all legal contracts.

5. How the System Works

  1. Collects the contract text from the user.
  2. Cleans unnecessary spaces and formatting.
  3. Converts the text into individual tokens.
  4. Checks brackets and nested structures using a PDA stack.
  5. Checks clause structure using predefined CFG patterns.
  6. Displays the validation result and detected errors.
